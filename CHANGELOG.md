# Changelog

## Unreleased

## 0.2

- Change the font size from the View menu or with ⌘+, ⌘- and ⌘0.
- Make Fst the Default Editor now covers `.ts` files, which macOS otherwise files as video. Click it again after updating to take over `.ts`.

### Fixes

- A font size or line height typed in Settings sticks after closing the window and relaunching Fst. Before, it was lost unless you pressed Return.

## 0.1.1

- Save As accepts any filename without appending `.md`, and documents are saved only when you ask.
- Wrap Lines and Show Line Numbers toggles in Settings and the View menu.
- Make Fst the Default Editor limits itself to code files.

### Fixes

- Unstyled text, the cursor and typing in dark mode use readable colors.
