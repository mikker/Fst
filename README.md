# Fst

A fast, minimal native macOS text editor. Single files, syntax highlighting, themes, and little else. macOS 14+.

[Download](https://github.com/mikker/Fst/releases/latest) · `brew install --cask mikker/tap/fst`

Build and launch: `just run`. Test: `just test`. [Development](Development.md) · [Releases](RELEASING.md).
